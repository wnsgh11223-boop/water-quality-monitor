# 화면설계서
## 수조 수질 탁도 감지 및 텔레그램 즉시 알림 서비스

> 본 서비스는 별도 웹/앱 UI 없이 텔레그램 봇이 모든 사용자 인터페이스 역할을 한다.

---

## 1. 화면 목록

| 화면 ID | 화면명 | 트리거 |
|--------|-------|-------|
| SCR-01 | 주의 알림 메시지 | 서버가 NTU 10~49 감지 시 자동 발송 |
| SCR-02 | 위험 알림 메시지 | 서버가 NTU ≥ 50 감지 시 자동 발송 |
| SCR-03 | /start 응답 화면 | 사용자가 /start 입력 시 |
| SCR-04 | /status 응답 화면 | 사용자가 /status 입력 시 |
| SCR-05 | /history 응답 화면 | 사용자가 /history 입력 시 |
| SCR-06 | 알 수 없는 명령어 응답 | 정의되지 않은 메시지 입력 시 |

---

## 2. 화면 상세 설계

---

### SCR-01 | 주의 알림 메시지

**트리거:** 서버가 NTU 10 이상 50 미만 데이터 수신 시 자동 전송
**발신자:** 봇 (자동)

```
┌─────────────────────────────────────┐
│  🤖 WaterBot                        │
├─────────────────────────────────────┤
│                                     │
│  ⚠️ [주의] 수질 이상 감지           │
│  ─────────────────────              │
│  • 탁도 : 15.3 NTU                  │
│  • 수준 : 주의 (10 NTU 이상)        │
│  • 감지 : 2026-06-29 14:32:05       │
│  • 장치 : tank-001                  │
│                                     │
└─────────────────────────────────────┘
```

**표시 항목:**
- 경고 이모지 + 경고 수준 텍스트
- 탁도 수치 (소수점 1자리)
- 임계값 기준 안내
- 감지 일시 (YYYY-MM-DD HH:MM:SS)
- 장치 ID

---

### SCR-02 | 위험 알림 메시지

**트리거:** 서버가 NTU 50 이상 데이터 수신 시 자동 전송
**발신자:** 봇 (자동)

```
┌─────────────────────────────────────┐
│  🤖 WaterBot                        │
├─────────────────────────────────────┤
│                                     │
│  🚨 [위험] 수질 이상 감지           │
│  ─────────────────────              │
│  • 탁도 : 63.7 NTU                  │
│  • 수준 : 위험 (50 NTU 이상)        │
│  • 감지 : 2026-06-29 14:32:05       │
│  • 장치 : tank-001                  │
│                                     │
└─────────────────────────────────────┘
```

**SCR-01과 차이점:**
- 이모지: ⚠️ → 🚨
- 수준 텍스트: "주의" → "위험"
- 임계값 기준: "10 NTU 이상" → "50 NTU 이상"

## 3. 봇 대화 흐름도

```
사용자 진입
    │
    ├── /start ──────────────→ SCR-03 (환영 메시지 + 명령어 안내)
    │
    ├── /status ─────────────→ SCR-04-A (데이터 있음)
    │                          SCR-04-B (데이터 없음)
    │
    ├── /history ────────────→ SCR-05-A (데이터 있음)
    │                          SCR-05-B (데이터 없음)
    │
    └── 기타 입력 ───────────→ SCR-06 (알 수 없는 명령어)

[서버 자동 발송]
    ├── NTU 10~49 감지 ──────→ SCR-01 (주의 알림)
    └── NTU ≥ 50 감지 ───────→ SCR-02 (위험 알림)
```

## 4. 메시지 공통 규칙

| 항목 | 규칙 |
|-----|------|
| 날짜 형식 | YYYY-MM-DD HH:MM:SS |
| 탁도 표시 | 소수점 1자리 (예: 15.3 NTU) |
| 경고 수준 표시 | ⚠️ 주의 / 🚨 위험 |
| 정상 상태 표시 | ✅ |
| 봇 이름 | WaterBot |
