## 2. 배경 및 문제 정의

### 2.1 현재의 불편함

| # | 문제 | 결과 |
|---|------|------|
| 1 | 매일 아침 날씨 앱을 직접 열어서 확인해야 함 | 바쁜 아침에 깜빡하고 우산 못 챙김 |
| 2 | 날씨 확인해도 옷차림을 매번 고민해야 함 | 시간 낭비, 옷 선택 실패 |
| 3 | 주간 날씨를 한눈에 보기 어려움 | 주말 일정 계획 어려움 |
| 4 | 날씨 앱마다 UI가 달라 원하는 정보 찾기 번거로움 | 불필요한 정보 과부하 |

### 2.2 해결 방향

Open-Meteo API로 날씨 데이터를 자동 수집하고, 매일 정해진 시간에 텔레그램으로 **오늘 날씨 + 옷차림 추천 + 주간 요약**을 한 번에 전송합니다. 사용자는 아침에 텔레그램 알림만 확인하면 됩니다.

## 3. 시스템 동작 원리

```
① 매일 07:30      ②  API 호출          ③ 데이터 파싱        ④ 알림 전송
  스케줄러 실행  →  Open-Meteo      →  날씨 + 옷차림    →  텔레그램 봇
                    날씨 API             추천 로직             즉시 발송
```

| 단계 | 동작 | 상세 |
|-----|------|------|
| ① 스케줄러 | 매일 07:30 자동 실행 | APScheduler로 시간 관리 |
| ② API 호출 | Open-Meteo API 요청 | 오늘 + 주간 7일 날씨 데이터 수신 |
| ③ 파싱 | 데이터 가공 | 날씨 코드 → 한국어 변환, 옷차림 계산 |
| ④ 알림 전송 | 텔레그램 메시지 발송 | 포맷에 맞게 메시지 생성 후 전송 |
| ⑤ 대기 | 다음 알림까지 대기 | 명령어 입력 시 즉시 응답 |

## 4. 주요 기능 상세

### 4.1 자동 날씨 알림

| 항목 | 내용 | 기준 |
|-----|------|------|
| 알림 시간 | 매일 07:30 (변경 가능) | `/alert HH:MM` 으로 설정 |
| 날씨 정보 | 날씨 상태, 최고/최저 기온, 강수확률 | Open-Meteo API |
| 주간 날씨 | 7일 요약 (강수확률 30% 이상 시 표시) | Open-Meteo API |
| 옷차림 추천 | 최고 기온 기준 자동 추천 | 아래 기준표 참고 |

### 4.2 옷차림 추천 기준

| 기온 범위 | 추천 옷차림 |
|---------|-----------|
| 28°C 이상 | 👕 반팔, 반바지 |
| 23°C ~ 27°C | 👔 반팔, 얇은 긴팔 |
| 17°C ~ 22°C | 🧥 얇은 가디건, 긴바지 |
| 12°C ~ 16°C | 🧣 자켓, 가디건 |
| 7°C ~ 11°C | 🧤 코트, 두꺼운 니트 |
| 6°C 이하 | 🧥 패딩, 두꺼운 코트 |

### 4.3 텔레그램 봇 명령어

| 명령어 | 기능 | 예시 |
|-------|------|------|
| `/start` | 봇 사용법 및 명령어 안내 | — |
| `/weather` | 현재 날씨 즉시 조회 | — |
| `/region 도시명` | 날씨 조회 지역 변경 | `/region Busan` |
| `/alert HH:MM` | 자동 알림 시간 변경 | `/alert 08:00` |

### 4.4 API 오류 대응

API 호출 실패 시 1회 재시도하고, 재시도도 실패하면 텔레그램으로 오류 안내 메시지를 발송합니다.

## 5. 시스템 구성도

```
[APScheduler]
    | 매일 07:30 자동 실행
    ↓
[Open-Meteo API] ──HTTPS──▶ [Python 서버]
                                  │
                           데이터 파싱 +
                           옷차림 추천 로직
                                  │
                     [Telegram Bot API] ──HTTPS──▶ [텔레그램 봇]
                                                        │
                                                  👤 사용자 핸드폰

[사용자 명령어] ──▶ [텔레그램 봇 Polling] ──▶ [Python 서버] ──▶ [응답 전송]
```

**Python 서버 역할** : API 호출 + 날씨 파싱 + 옷차림 추천 + 텔레그램 메시지 전송 + 명령어 처리

## 6. 소프트웨어 구성

| 파일 | 역할 | 주요 내용 |
|-----|------|---------|
| `config.py` | 설정 파일 | 텔레그램 토큰, 채팅방 ID, 기본 도시, 알림 시간 |
| `weather.py` | 날씨 모듈 | Open-Meteo API 호출, 데이터 파싱, 메시지 포맷 |
| `bot.py` | 봇 메인 | 텔레그램 봇 실행, 스케줄러, 명령어 처리 |

| 라이브러리 | 용도 |
|---------|------|
| `python-telegram-bot` | 텔레그램 봇 API 연동 |
| `apscheduler` | 자동 알림 스케줄링 |
| `requests` | Open-Meteo API HTTP 호출 |

> ✅ **API 키 불필요** : Open-Meteo는 무료이며 가입이나 API 키 발급이 필요 없습니다.

## 8. 개발 일정

| 단계 | 기간 | 할 일 | 완료 기준 |
|-----|------|-------|---------|
| 1단계 기획 및 설계 | 1시간 | SRS, 화면설계서, 플로우차트 작성 | 문서 완성 |
| 2단계 환경 세팅 | 30분 | Python 라이브러리 설치, 텔레그램 봇 생성 | 봇 토큰 발급 완료 |
| 3단계 날씨 모듈 개발 | 1시간 | Open-Meteo API 연동, 데이터 파싱 | 날씨 데이터 정상 수신 |
| 4단계 봇 개발 | 2시간 | 텔레그램 봇 + 스케줄러 + 명령어 구현 | 명령어 정상 응답 |
| 5단계 테스트 | 30분 | 전체 기능 테스트, 오류 수정 | 자동 알림 정상 수신 |
| 6단계 배포 | 30분 | GitHub push, 문서 정리 | 전체 코드 업로드 완료 |

> 📦 **총 개발 시간 : 약 5~6시간 (당일 완성 가능)**
