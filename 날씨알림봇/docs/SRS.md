# 소프트웨어 요구사항 명세서 (SRS)
## 날씨 자동 알림 텔레그램 봇

---

## 1. 서론 (Introduction)

### 1.1 목적 (Purpose)

본 문서는 날씨 정보를 자동으로 수집하여 매일 정해진 시간에 텔레그램으로 전송하는 봇 서비스 개발을 위한 요구사항을 정의한다.

### 1.2 범위 (Scope)

- **사용자:** 날씨 정보를 매일 자동으로 받고 싶은 모든 사람
- **기능:** 날씨/미세먼지 자동 알림, 옷차림 추천, 명령어 조회, 지역/시간 설정
- **목표:** 매일 아침 날씨 확인을 자동화하여 편의성 향상

### 1.3 정의 및 약어

| 용어 | 설명 |
|-----|------|
| API | Application Programming Interface |
| 미세먼지 | PM10 — 직경 10㎛ 이하 입자상 물질 |
| 초미세먼지 | PM2.5 — 직경 2.5㎛ 이하 입자상 물질 |
| 스케줄러 | 특정 시간에 자동으로 작업을 실행하는 모듈 |
| 텔레그램 봇 | Telegram Bot API로 동작하는 자동화 메시지 계정 |

### 1.4 참조 문서

- Telegram Bot API: https://core.telegram.org/bots/api
- OpenWeatherMap API: https://openweathermap.org/api
- 에어코리아 API: https://www.data.go.kr (미세먼지)

---

## 2. 전체 설명 (Overall Description)

### 2.1 제품 관점

본 시스템은 날씨 API와 미세먼지 API를 주기적으로 호출하여 텔레그램 봇으로 결과를 전송한다. 별도 서버 없이 로컬 환경에서 실행된다.

**시스템 흐름:**
```
스케줄러 (매일 07:30 자동 실행)
    ↓
날씨 API + 미세먼지 API 호출
    ↓
데이터 파싱 + 옷차림 추천 로직
    ↓
텔레그램 봇 메시지 전송
    ↓
👤 사용자 수신
```

### 2.2 제품 기능 요약

- 매일 아침 자동 날씨 알림 (스케줄러)
- 오늘 날씨 + 주간 7일 날씨 요약
- 미세먼지/초미세먼지 등급 포함
- 기온 기반 옷차림 추천
- `/날씨` 명령어로 언제든 즉시 조회
- `/지역 도시명` 명령어로 지역 변경
- `/알림설정 HH:MM` 명령어로 알림 시간 변경

### 2.3 사용자 특성

| 사용자 유형 | 특성 |
|-----------|------|
| 일반 사용자 | 텔레그램 앱만 있으면 사용 가능, IT 지식 불필요 |

### 2.4 제약 조건

- 운영 환경: 로컬 PC (Python 실행 환경)
- 날씨 API: OpenWeatherMap 무료 플랜 (호출 제한 60회/분)
- 알림 채널: 텔레그램 봇 단일 채널
- 인터넷 연결 필수

### 2.5 가정 및 의존성

- 텔레그램 봇 토큰 및 채팅방 ID 사전 발급 가정
- OpenWeatherMap API 키 사전 발급 가정
- 프로그램 실행 중에는 PC가 켜져 있어야 함

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 자동 알림

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| FR-01 | 매일 설정된 시간(기본 07:30)에 자동으로 날씨 알림을 전송한다 | Must |
| FR-02 | 알림에는 오늘 날씨 상태, 최고/최저 기온, 강수확률이 포함된다 | Must |
| FR-03 | 알림에는 미세먼지(PM10), 초미세먼지(PM2.5) 등급이 포함된다 | Must |
| FR-04 | 알림에는 기온 기반 옷차림 추천이 포함된다 | Must |
| FR-05 | 알림에는 주간 7일 날씨 요약이 포함된다 | Should |

### 3.2 명령어

| ID | 요구사항 | 우선순위 |
|----|---------|---------|
| FR-06 | `/날씨` 입력 시 현재 날씨 정보를 즉시 반환한다 | Must |
| FR-07 | `/지역 도시명` 입력 시 해당 도시 날씨로 변경된다 | Must |
| FR-08 | `/알림설정 HH:MM` 입력 시 알림 시간이 변경된다 | Must |
| FR-09 | `/시작` 입력 시 봇 사용법과 명령어 목록을 반환한다 | Must |
| FR-10 | 정의되지 않은 명령어 입력 시 안내 메시지를 반환한다 | Must |

### 3.3 옷차림 추천 로직

| 기온 범위 | 추천 옷차림 |
|---------|-----------|
| 28°C 이상 | 반팔, 반바지 |
| 23°C ~ 27°C | 반팔, 얇은 긴팔 |
| 17°C ~ 22°C | 얇은 가디건, 긴바지 |
| 12°C ~ 16°C | 자켓, 가디건 |
| 7°C ~ 11°C | 코트, 두꺼운 니트 |
| 6°C 이하 | 패딩, 두꺼운 코트 |

## 4. 비기능 요구사항 (Non-functional Requirements)

| ID | 요구사항 | 기준치 |
|----|---------|-------|
| NFR-01 | 명령어 입력 후 응답 시간 | 3초 이내 |

## 5. 외부 인터페이스 요구사항

### 5.1 사용자 인터페이스

- 별도 앱/웹 없음
- 텔레그램 앱으로 모든 상호작용

### 5.2 소프트웨어 인터페이스

| 구성 요소 | 기술 |
|---------|------|
| 언어 | Python 3.12 |
| 날씨 API | OpenWeatherMap API |
| 미세먼지 API | 에어코리아 API (공공데이터포털) |
| 알림 채널 | Telegram Bot API |
| 스케줄러 | APScheduler |

### 5.3 통신 인터페이스

- 모든 외부 API 통신: HTTPS
- 텔레그램 → 봇: Polling 방식

## 6. 시스템 아키텍처 개요

```
[스케줄러] ──매일 07:30──▶ [날씨 API 호출] ──▶ [데이터 파싱]
                                                      │
                          [미세먼지 API 호출] ──▶ [데이터 합산]
                                                      │
                                               [메시지 생성]
                                                      │
                                            [텔레그램 봇 전송]
                                                      │
                                               [👤 사용자]

[사용자 명령어] ──▶ [봇 Polling] ──▶ [명령어 처리] ──▶ [응답 전송]
```

## 8. 부록

### 8.1 용어집

| 용어 | 설명 |
|-----|------|
| PM10 | 미세먼지 (직경 10㎛ 이하) |
| PM2.5 | 초미세먼지 (직경 2.5㎛ 이하) |
| APScheduler | Python 스케줄링 라이브러리 |
| Polling | 봇이 주기적으로 텔레그램 서버에 새 메시지를 확인하는 방식 |

### 8.2 MVP 범위 외

- 다중 사용자 지원
- 웹 대시보드
- 날씨 히스토리 저장
- 강수량, 풍속 등 상세 기상 정보
- 푸시 알림 외 SMS/이메일 지원
