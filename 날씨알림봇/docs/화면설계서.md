## 3. 봇 대화 흐름도

```
사용자 입력
    ├── /시작 ──────────────→ SCR-02 (사용법 안내)
    ├── /날씨 ──────────────→ SCR-03 (현재 날씨)
    ├── /지역 도시명 ────────→ SCR-04-A (성공) / SCR-04-B (실패)
    ├── /알림설정 HH:MM ─────→ SCR-05-A (성공) / SCR-05-B (실패)
    └── 기타 입력 ──────────→ SCR-07 (알 수 없는 명령어)

[자동 발송]
    └── 매일 07:30 ─────────→ SCR-01 (자동 날씨 알림)
    └── API 실패 시 ─────────→ SCR-06 (오류 안내)
```
