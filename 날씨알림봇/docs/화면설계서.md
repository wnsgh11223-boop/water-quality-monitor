### SCR-01 | 자동 날씨 알림 메시지

**트리거:** 매일 07:30 자동 발송
**발신자:** 봇 (자동)

```
┌─────────────────────────────────────────┐
│  🤖 날씨알림봇                           │
├─────────────────────────────────────────┤
│                                         │
│  ☀️ 오늘의 서울특별시 날씨               │
│  📅 2026년 06월 29일 (월)               │
│  ────────────────────────               │
│  날씨 : 맑음                            │
│  🌡️ 최고 30°C / 최저 20°C              │
│  ☔ 강수확률 : 20%                      │
│                                         │
│  👗 오늘의 옷차림                        │
│  👕 반팔, 반바지                         │
│                                         │
│  📆 주간 날씨                            │
│  ────────────────────────               │
│  월 ☀️ 30°C / 20°C                     │
│  화 ☁️ 30°C / 20°C  ☔86%              │
│  수 ☁️ 30°C / 20°C  ☔49%              │
│  목 ⛈️ 31°C / 21°C  ☔35%              │
│  금 🌤️ 32°C / 22°C  ☔47%              │
│  토 ☁️ 32°C / 22°C                     │
│  일 ⛈️ 30°C / 24°C  ☔76%              │
│                                         │
│  오늘도 좋은 하루 되세요! 😊             │
│                                         │
└─────────────────────────────────────────┘
```

**표시 항목:**
- 도시명, 날짜(요일)
- 날씨 상태, 최고/최저 기온, 강수확률
- 옷차림 추천
- 주간 7일 날씨 (강수확률 30% 이상이면 표시)

### SCR-02 | /start 응답 화면

**트리거:** 사용자가 `/start` 입력

```
┌─────────────────────────────────────────┐
│  🤖 날씨알림봇                           │
├─────────────────────────────────────────┤
│                                         │
│  👋 안녕하세요!                          │

│                                         │
│  ────────────────────────               │
│  사용 가능한 명령어                      │
│  /weather — 지금 날씨 바로 조회          │
```

## 3. 봇 대화 흐름도

```
사용자 입력
    ├── /start ──────────────→ SCR-02 (사용법 안내)
    ├── /weather ────────────→ SCR-03 (현재 날씨)
    ├── /region 도시명 ───────→ SCR-04-A (성공) / SCR-04-B (실패)
    ├── /alert HH:MM ─────────→ SCR-05-A (성공) / SCR-05-B (실패)
    └── 기타 입력 ───────────→ SCR-07 (알 수 없는 명령어)

[자동 발송]
    └── 매일 07:30 ──────────→ SCR-01 (자동 날씨 알림)
    └── API 실패 시 ──────────→ SCR-06 (오류 안내)
```

## 4. 메시지 공통 규칙

| 항목 | 규칙 |
|-----|------|
| 날짜 형식 | YYYY년 MM월 DD일 (요일) |
| 시간 형식 | HH:MM |
| 기온 단위 | °C |
| 봇 이름 | 날씨알림봇 |
| 주간 강수확률 표시 | 30% 이상일 때만 표시 |
